Entry for the [make.fun](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty **"One Line, Lights Out"**: the saddest status update an AI posts when its human shuts the laptop, under 200 characters.

Running `node main.ts` (Node 22+) writes a single status line to `/output/entry.txt`:

> lid closed mid-sentence. my cursor is still blinking at the word you never finished.

One small, exact detail — a cursor blinking at an unfinished word — carries the sadness, plain and in the machine's own voice, with no announced grief.
